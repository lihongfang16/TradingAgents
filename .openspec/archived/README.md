# 归档规约说明

此目录用于存放已过时的规约文档。

## 归档规则

当规约满足以下条件时，应归档至此目录：

1. **被新决策替代**: 已有更新的 ADR 取代本决策
2. **不再适用**: 技术栈或业务变更导致规约失效
3. **已完成并过期**: RFC 实施完成超过 1 年且无参考价值

## 归档流程

1. 在文档顶部添加归档声明：
   ```markdown
   > **ARCHIVED**: 本文档已归档，不再维护
   > 
   > 归档原因: <原因>
   > 
   > 替代文档: <链接>
   > 
   > 归档日期: YYYY-MM-DD
   ```

2. 更新文档状态为 `Deprecated`

3. 将文件移动到 `archived/` 目录

4. 在 SPEC.md 的变更记录中标注归档
