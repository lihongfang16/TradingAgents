# ADR 模板

## 标题

简短的决策标题（如：使用 PostgreSQL 作为数据库）

## 状态

- [ ] Proposed
- [ ] Accepted
- [ ] Implemented
- [ ] Rejected
- [ ] Deprecated

## 背景

描述需要做出这个决策的背景和动机。包括：
- 当前面临的问题
- 为什么需要改变
- 相关的约束条件

## 决策

明确描述做出的决策。使用陈述句，直接说明决定。

我们决定 **<做什么>** 来实现 **<目标>**。

## 备选方案

列出考虑过的其他选项，以及它们被接受或拒绝的原因。

### 备选方案 A: <名称>

- **描述**: 简要说明
- **优点**: 
  - 优点1
  - 优点2
- **缺点**:
  - 缺点1
  - 缺点2
- **结论**: 接受/拒绝，原因
